# 🚀 Deadline & Task Reminder Assistant

> **A cloud-based productivity assistant that helps users stay ahead of deadlines through intelligent task organization, real-time countdowns, and urgency-driven prioritization.** Built with modern web technologies and deployed on Google Cloud Run for fast, scalable, and reliable access.

# 📖 Project Description

Managing multiple assignments, projects, meetings, and personal commitments can quickly become overwhelming. Traditional to-do applications often act as passive lists, making it easy for important deadlines to get buried until the last minute.

**Deadline & Task Reminder Assistant** provides a centralized dashboard that continuously highlights what matters most. By combining live countdown timers, automatic urgency-based sorting, and an intuitive interface, the application enables users to prioritize work effectively and reduce the chances of missing important deadlines.

Designed with scalability in mind, the application is fully containerized using Docker and deployed on **Google Cloud Run**, making it a lightweight, production-ready solution that is accessible from anywhere.

> **A ready-to-use, cloud-hosted productivity solution that empowers students, professionals, and teams to stay organized, prioritize effectively, and complete tasks before deadlines become critical.**

---

# ✨ Key Features

- 📅 **Deadline-Centric Task Management**
  - Create and manage tasks with titles, descriptions, categories, priorities, and deadlines.

- ⏳ **Live Countdown Timers**
  - Displays the remaining days, hours, and minutes until every deadline.

- 🚨 **Urgency-Based Prioritization**
  - Automatically sorts tasks so the most time-sensitive items appear first.

- 🎨 **Visual Priority Indicators**
  - Color-coded urgency levels help users instantly identify critical tasks.

- 📈 **Task Progress Tracking**
  - Organize work through **To-Do**, **In Progress**, and **Completed** stages.

- 📱 **Responsive User Interface**
  - Optimized for desktops, tablets, and mobile devices.
